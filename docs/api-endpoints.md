# API Endpoints

## Authentication

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/refresh`

## Tasks

- `GET /api/tasks`
- `POST /api/tasks`
- `PUT /api/tasks/{id}`
- `DELETE /api/tasks/{id}`
- `POST /api/tasks/{id}/complete`

## Planner

- `POST /api/planner/generate`
- `GET /api/planner/today`

## Habits

- `GET /api/habits`
- `POST /api/habits`
- `PUT /api/habits/{id}/progress`

## Expenses

- `GET /api/expenses`
- `POST /api/expenses`
- `GET /api/expenses/insights`

## Notifications

- `GET /api/notifications`
- `POST /api/notifications`
- `POST /api/notifications/test`

## Chat

- `POST /api/chat`
- `GET /api/chat/history`

## Dashboard

- `GET /api/dashboard`

## System

- `GET /api/health`
